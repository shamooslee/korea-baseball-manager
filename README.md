초등학교 4학년이 만든 야구 매니저 게임입니다.

## 주요 기능

| 기능 | 설명 |
|---|---|
| 팀 선택 | 창작 팀 10개 중 하나를 골라 감독이 됩니다 |
| 라인업 편성 | 타순 9명과 선발투수를 직접 정합니다 |
| 직접 플레이 | 코스를 조준해 공을 던지고, 타이밍에 맞춰 스윙합니다 |
| 볼-스트라이크 카운트 | 4볼 볼넷, 3스트라이크 삼진, 파울까지 실제 야구 규칙 |
| 투수 체력·교체 | 투수가 지치면 제구와 구위가 떨어져 불펜으로 교체해야 합니다 |
| 오늘의 컨디션 | 날마다 선수 컨디션이 바뀝니다 (최상 / 좋음 / 보통 / 나쁨) |
| 선수 육성 | 경기 출전으로 레벨업, 코인으로 훈련, 안 쓰는 선수로 합성 |
| 시즌 기록 | 타율·홈런·타점·방어율을 선수별로 기록 |
| 리그 순위표 | 10개 팀의 승패·득실차를 한눈에 |
| 뽑기 · 상점 · 미션 | 데일리 선수, 카드팩, 이달의 선수, 골든글러브 |
| 실시간 대결 | WebSocket 서버로 친구와 1:1 대결 |
| 자동 저장 | 게임을 껐다 켜도 기록이 그대로 남습니다 |

## 게임 밸런스

실제 프로야구 통계에 가깝게 맞췄습니다. (108경기 시뮬레이션 기준)

| 지표 | 이 게임 | 실제 프로야구 |
|---|---|---|
| 팀 타율 | .258 | 약 .270 |
| 경기당 팀 득점 | 5.0 | 약 5.0 |
| 경기당 팀 홈런 | 1.3 | 약 1.0 |
| 경기당 팀 볼넷 | 3.3 | 약 3.5 |

## 실행 방법

### 게임만 하기
`index.html` 파일을 다운로드해서 브라우저(크롬)로 열면 됩니다. 설치할 것이 없습니다.

### 실시간 대결까지 하기
```bash
npm install ws
node server.js
```
서버를 켠 다음, 게임의 **실시간 대결** 화면에서 `ws://localhost:8080` 으로 접속하세요.

## 만든 것에 대해

- 등장하는 팀 10개(광주 백호, 대구 불사자, 서울 쌍별, 서울 흑곰, 수원 마법단, 인천 비룡, 부산 바다거인, 대전 하늘수리, 창원 번개공룡, 고척 영웅단)와 선수 이름은 **모두 직접 만든 것**입니다.
- 실제 프로야구 구단명, 엠블럼, 선수 이름은 사용하지 않았습니다.
- 3D 화면은 [three.js](https://threejs.org/)를 사용합니다.
